# Factory Asset Map

> 🇻🇳 Giao diện tiếng Việt. Hướng dẫn sử dụng: [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

Interactive digital floor plan for **locating, searching and managing physical assets** across a factory.
Built with plain HTML, CSS and vanilla JavaScript (no build step). Front-end can be hosted on **GitHub Pages**;
shared data is stored on **Cloudflare (Worker + D1 database)**. No login is needed to open the app.

> ⚠️ **Demo data.** The factory, floor plans, coordinates, assets and history shipped with this project describe a
> **fictional coffee factory** and are illustrative only — they are not actual factory records. Replace them with
> your own drawings and asset register (see *Replacing the demo* below).

## Features

| Tab | What it does |
|---|---|
| **Dashboard** | KPI cards (total / active / inspection due / out of service / zones), assets by status, category, department and zone, recently updated assets, recent location changes |
| **Factory Map** | SVG floor plan per floor, zones, asset markers (colour = status, shape = category), zoom / pan / pinch, search → fly to asset, filters (floor, zone, category, department, status), legend, detail panel, **move asset by clicking the map**, live cursor coordinates |
| **Asset Register** | Search, filter, sort, paginate; add / edit / delete with validation (unique Asset ID, required fields, 0–100 coordinates, zone-on-floor); Locate; CSV / Excel import (with preview & error report) and export |
| **Factory Zones** | Factory → Floor → Department → Zone → Asset tree; add / edit / delete zones (draw boundary on map), floors (import floor plan SVG / PNG / JPG), departments; asset counts |
| **Location History** | Append-only log of every location change (previous / new floor, zone, X-Y, location code, user, reason); filters; CSV / Excel export |
| **QR Codes** | QR per asset (Asset ID + link to the asset on the map), preview, PNG download, printable label sheets, lookup by keyboard-wedge scanner or camera (BarcodeDetector) |
| **Settings & Guide** | General settings, users, categories, statuses, location coding rules, data backup / restore / reset, import-export instructions, floor plan (CAD/PDF → SVG) guide, user guide, future integrations |

### Identifiers

* **Asset ID** – permanent, e.g. `AST-EQP-0001` (`AST-<category>-<seq>`). Never changes when the asset moves and is never reused.
* **Location Code** – recalculated on every move, e.g. `F1-PR-EXT-X025-Y040` = Floor 1 · Production · Extraction · X 25 % · Y 40 %.
* **Coordinates** – normalized **0–100 %** of the floor drawing; **origin top-left, X → right, Y ↓ down**; stored at 0.1 % precision independent of screen resolution.

## Quick start (local)

```powershell
python tools/serve.py
```

Open <http://127.0.0.1:8765/>. (Opening `index.html` directly also works; data then stays in that browser.)

With `js/config.js` → `apiBase: ''` the app runs **local-only** (LocalStorage). Set `apiBase` to your Worker URL to share data.

## Architecture

```
GitHub Pages (static)                        Cloudflare
┌────────────────────────────┐   HTTPS/JSON   ┌───────────────────────────────┐
│ index.html, css/, js/      │ ─────────────▶ │ Worker  worker/src/index.js   │
│  store.js  (domain logic)  │ ◀───────────── │  /api/changes  /api/replace   │
│  remote.js (sync, 20 s)    │                │ D1 database  (records table)  │
│  LocalStorage = offline    │                └───────────────────────────────┘
│  cache                     │
└────────────────────────────┘
```

* `js/store.js` – normalized data model (floors, departments, zones, categories, statuses, users, **assets** (master data), **locations** (current position), **history** (append-only)), validation, location coding.
* `js/remote.js` – record-level sync: pushes only changed records, pulls others' changes every 20 s, works offline and catches up later. Conflicting new Asset IDs are rejected by the server.
* `worker/` – Cloudflare Worker API + D1 schema. Enforces append-only history and unique, never-reused Asset IDs. Full data replacement (reset / restore / clear) requires the `ADMIN_KEY` secret.

## Replacing the demo with your factory

1. Factory Zones → Floors: edit floor codes/names, **Import plan** (SVG preferred) for each floor.
2. Delete / redefine zones and **draw their boundaries** on the map.
3. Import your asset register from CSV / Excel (template `templates/mau-nhap-tai-san.csv`).
4. Settings → General: set the factory name and the **QR base URL**; print QR labels.

Do not enter coordinates you have not verified on site — sample coordinates are demo data only.

## Security note

As requested, the app has **no login**: anyone with the link can view and edit assets. History cannot be deleted
through the API, and replacing all data needs the admin key. For production use consider Cloudflare Access or an
edit key in front of the Worker (see docs/DEPLOYMENT.md).
